# 04 — MVP1: F9 menu

**Goal:** one discoverable place for everything that isn't worth a dedicated F-key, without
growing into Midnight Commander's wall of options. The menu exists to teach shortcuts, so every
item shows its key.

## Design rules

- **Four menus, about six items each.** If a menu needs a scrollbar, it has too much in it.
- **Menus act on the active panel.** No separate "Left" and "Right" menus (a common point of
  confusion in NC and MC); the *Panel* menu always means "the panel you're in".
- **Every item has a shortcut,** shown right-aligned, so the menu doubles as a cheat sheet.
- **No settings maze.** Options holds a handful of toggles; anything rare goes in a JSON settings
  file.
- `F9` opens the bar with *File* highlighted; `←/→` moves between menus; `Esc` or `F9` closes it.
  Mouse click works too.


## Supporting features that come with MVP1

These are small, and the menu items above depend on them:

1. **Persisted state** (`~/.config/myc/state.json`): last directory, sort and hidden-file
   toggle per panel, and which panel was active.
2. **Settings file** (`~/.config/myc/settings.json`): confirmations, theme name, startup
   behaviour. Read via Terminal.Gui's configuration system where that fits, otherwise a small
   `System.Text.Json` model.
3. **File-system watching:** panels auto-refresh on external changes (debounced).
4. **Select by pattern:** a small dialog with glob input and a live "N matches" count.
5. **Go to path:** text field with Tab completion and a short history.
6. **Sort indicator** in the panel header (`Name ▲`).

## Explicitly not in MVP1

To keep it minimal, these wait for later milestones:
- The theme editor and user themes (MVP2).
- Panel modes: preview and info (MVP3).
- Viewer and editor, search, bookmarks, archives, remote file systems (see the roadmap).
- A built-in shell or command line.

## Build order

1. Persisted state and settings model.
2. Menu bar wired to the existing command table (no new logic, only discoverability).
3. Sort modes and the hidden-files toggle.
4. Select / deselect by pattern, invert, select all, clear.
5. Go to path with completion; same-directory and swap panels.
6. File-system watcher.
7. Reveal in Finder (`open -R`), the About dialog, and the Options toggles.

## Definition of done
- Every menu item works and shows its shortcut.
- Restarting the app restores both panels to where you left them.
- A new user can find every MVP0 and MVP1 feature from F9 without reading docs.
