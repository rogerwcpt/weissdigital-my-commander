# 03 — MVP0: Dual panels and core F-key operations

**Goal:** a daily-drivable dual-panel file manager for the basic copy / move / rename / mkdir /
delete workflow, with Norton muscle memory and a modern look.

## Screen layout

```
╭─ ~/Projects ─────────────────────────╮╭─ ~/Downloads ────────────────────────╮
│ Name                    Size Modified││ Name                    Size Modified│
│ ..                                   ││ ..                                   │
│ ▸ Viewism/             <DIR> 03 Oct  ││ ▸ old-builds/          <DIR> 12 Sep  │
│ ▸ Sentrism/            <DIR> 01 Oct  ││ • invoice-0923.pdf    214 KB 23 Sep  │
│ ▸ Wordflexion/         <DIR> 28 Sep  ││ • photo-reef-01.jpg   4.1 MB 20 Sep  │
│   notes.md             2 KB 04 Oct   ││   readme.txt            1 KB 02 Sep  │
│                                      ││                                      │
├──────────────────────────────────────┤├──────────────────────────────────────┤
│ notes.md   2 KB   04 Oct 2026 11:02  ││ 2 marked · 4.3 MB                    │
╰──────────────────────────────────────╯╰──────────────────────────────────────╯
 1 Help  2 Rename  3 —  4 —  5 Copy  6 Move  7 MkDir  8 Delete  9 Menu  10 Quit
```

- Two equal-width panels; the **active panel** has an accent-coloured border and title, the
  inactive one is dimmed.
- Columns: Name, Size (`<DIR>` for folders), Modified. Columns collapse gracefully at narrow
  widths (Modified goes first, then Size).
- Footer per panel: details of the entry under the cursor, or a mark summary (count and total
  size) when anything is marked.
- Bottom function-key bar, **clickable with the mouse**, with unimplemented keys greyed out.
- Rounded, thin box-drawing lines; no blue background.

## Requirements

### 1. Dual panels
- Left and right panels, each with independent directory, cursor, marks and sort.
- `Tab` switches the active panel.
- Startup: left = current working directory, right = home (MVP1 persists the last locations).
- Sorting (fixed in MVP0): `..` first, then directories, then files; natural, case-insensitive
  order (`file2` before `file10`, the way Finder does it).
- Hidden (dot) files are hidden by default; MVP1 adds the toggle.

### 2. Space to mark and move down
- `Space` toggles the mark on the entry under the cursor, then moves the cursor down one row.
- `Insert` does the same, for Norton purists on full keyboards.
- `..` can't be marked.
- Marked entries show a `•` glyph and the accent "marked" colour (never colour alone).
- Marks are kept by name, so they survive refreshes; they are cleared after a successful
  operation on them.

### 3. F5 to copy to the other panel
- Acts on the effective selection: marked items, or the cursor item if nothing is marked.
- Dialog: `Copy 3 items to:` with an editable destination (defaults to the other panel's
  directory), plus `[ Copy ]  [ Cancel ]`.
- Directories are copied recursively; symlinks are copied as links.
- **Conflicts:** Overwrite / Skip / Rename (keep both: `name (2).ext`) / apply-to-all / Cancel.
- **Progress dialog:** current file, overall progress bar, bytes and items done, elapsed time,
  and a `[ Cancel ]` button. Small copies (under ~0.5 s) finish without flashing a dialog.
- **Guards:** refuse copying a directory into itself or its own subtree; when source and
  destination are the same directory, offer "Duplicate as `name copy`".
- Afterwards: marks cleared, both panels refreshed, cursor kept in place.

### 4. Left / Right arrow navigation
- `→` on a directory enters it, with the cursor on the first entry.
- `→` on a file does nothing in MVP0 (reserved for preview in MVP3).
- `←` goes to the parent directory **with the cursor on the folder you just left**, so
  `→` then `←` is a no-op.
- `Enter` on a directory enters it; `Enter` on a file opens it with the default macOS app
  (`open`).
- `↑ ↓ PgUp PgDn Home End` move the cursor as expected.
- Errors (no permission, folder gone) show a short inline message in the panel footer and stay
  where you are.

### 5. F8 to delete with confirmation
- Acts on the effective selection.
- Confirmation dialog lists what will happen: `Move 3 items to Trash?` with a preview of the
  first few names, plus `[ Move to Trash ]  [ Cancel ]`. **Cancel is the default button.**
- `Shift+F8`: permanent delete, with a stronger confirmation (`Permanently delete 3 items? This
  cannot be undone.`).
- Non-empty folders: one combined confirmation, not one per folder.
- Uses the same job and progress infrastructure as copy, for large trees.

### 6. Not the Norton blue and yellow
The default theme is **"Graphite"**: a dark, neutral theme with a single accent.

| Role | Proposal |
| --- | --- |
| Background | Terminal default (inherits the user's terminal background) |
| Normal text | Soft grey `#C9CCD1` |
| Directories | Bold, near-white `#E8EAED` with the `▸` glyph |
| Cursor row | Subtle highlight `#2E3440` background and bold text |
| Marked | Accent teal `#4FB8A8` with the `•` glyph |
| Active border/title | Accent teal |
| Inactive border | Dim grey `#5C6370` |
| Danger (delete dialogs) | Muted red `#E06C75` |

Using the terminal's own background makes the app blend into whatever terminal theme you
already use, which goes a long way towards feeling native. `NO_COLOR` is honoured: no colours,
with state shown by glyphs and bold/inverse only. Themes are defined as data from day one, even
though the picker arrives in MVP2.

### 7. F2 to rename
- Renames the item under the cursor (not the marks; batch rename comes later).
- Dialog with a text field prefilled with the current name and the **base name pre-selected**
  (without the extension), the way Finder does it.
- Validation: empty name, `/` in the name, and name already exists (offer to cancel or pick
  another name). Case-only renames (`readme` to `README`) must work on case-insensitive APFS.
- The cursor follows the renamed item after re-sorting.

### 8. F7 to create a directory
- Dialog: `New folder name:` text field.
- **If one or more items are marked**, show an extra checkbox:
  `[ ] Move selection into new folder?` (unchecked by default), with a hint line such as
  `3 items marked`.
- Without the checkbox: create the folder and put the cursor on it.
- With the checkbox: create the folder, move the marked items into it (same job and conflict
  handling as F6), clear the marks, and put the cursor on the new folder.
- Nested paths (`a/b/c`) are allowed and create intermediate folders.

### 9. F6 to move the selection
F6 moves the effective selection to the other panel, the Norton meaning and the partner of F5.
- Same dialog, conflict handling and progress as F5, titled `Move`.
- On the same volume, a rename (instant); across volumes, copy then delete the source, only
  after each item has been copied successfully.
- `Esc` in a panel with marks clears all marks (no dialog, nothing touched on disk).

### Also in MVP0 (implicit essentials)
- `F10` or `Ctrl+Q` to quit (with confirmation only if a job is running).
- `Ctrl+R` to refresh the active panel.
- `Esc` closes dialogs; `Enter` confirms the default button.
- `F1`: a simple key-reference overlay generated from the key binding table.
- Window resize is handled live.

## Function keys on macOS
F-keys are the core of the Norton experience and the biggest macOS risk. MVP0 ships with:

1. **Clickable function-key bar**: always works.
2. **`Esc` then digit** (`Esc 5` = F5, `Esc 0` = F10), compatible with Midnight Commander, and
   works in every terminal without any configuration.
3. **`Option+digit`** where the terminal sends Option as Meta (iTerm2, Ghostty and WezTerm can).
4. A short **"Terminal setup" section in the README** covering "Use F1, F2… as standard function
   keys" and freeing F-keys that Terminal.app or Mission Control capture.

## Build order (suggested tasks)

1. Solution skeleton, CI build (`dotnet build` + tests on macOS runner).
2. Core: `FileEntry`, directory listing, natural sorting, effective selection. Tests.
3. `FilePanelView`: drawing, cursor, scrolling, marks, header and footer. Theme roles wired.
4. Dual-panel shell: layout, Tab, function-key bar, F10, resize.
5. Navigation: `← → Enter`, cursor restore on parent, error handling.
6. Key binding table, F1 overlay, `Esc`+digit fallback.
7. Rename (F2) and mkdir (F7) without the move option.
8. Job infrastructure: pre-scan, progress, cancellation, conflict questions. Tests.
9. Copy (F5), then Move (F6), then F7's "move selection into new folder".
10. Trash and permanent delete (F8 / Shift+F8) via the macOS platform layer.
11. Polish pass: narrow widths, long names, NFD names, `NO_COLOR`, manual terminal matrix.

## Definition of done
- All nine brief items work in Ghostty, iTerm2 and Terminal.app on macOS.
- Core operations covered by tests, including cancellation and conflicts.
- No crash on permission errors, broken symlinks or directories vanishing.
- Copying 10k small files shows smooth progress and can be cancelled cleanly.
